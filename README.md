# Gestión de Notas de Alumnos

Proyecto desarrollado con fines académicos para practicar el manejo de archivos mediante File Reader y File Writer.

La aplicación permite leer y procesar los datos de diferentes alumnos junto con sus calificaciones, calcular automáticamente la nota media de cada uno y generar un nuevo archivo con los resultados obtenidos.

El archivo generado se guarda automáticamente en la carpeta raíz del proyecto, facilitando así la consulta de las notas una vez finalizado el procesamiento.

## Objetivos
·Practicar la lectura de archivos mediante File Reader.

·Aprender a escribir y generar archivos utilizando File Writer.

·Procesar y calcular las notas medias de los alumnos.

·Trabajar con datos almacenados en archivos.

·Automatizar la generación de resultados mediante un programa.

Este proyecto forma parte de mi proceso de aprendizaje y está orientado principalmente a reforzar los conocimientos sobre gestión de archivos y procesamiento de datos.
